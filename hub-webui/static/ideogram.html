Créditos y método

Vía principal — JSON + bounding boxes. Ideogram 4 se entrenó con captions JSON estructurados. Estructurar el prompt en varias cajas (sujeto + entorno) usa el modelo como fue diseñado y evita los falsos positivos del filtro de seguridad, sin pérdida de calidad.

Nodos nativos de ComfyUI (soporte Ideogram 4 día-0, PR de kijai / Comfy-Org): DualModelGuider, Ideogram4Scheduler, CreateBoundingBoxes, BuildJsonPromptIdeogram.

Detección del banner de bloqueo inspirada en el nodo ComfyUI-BlockGuard de INSANEF00L / Dragon7108 (github.com/Dragon7108/ComfyUI-BlockGuard), reimplementada aquí como análisis de imagen para no depender de un nodo custom.
